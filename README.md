# Saúde

App pessoal de peso, bioimpedância, treinos, diário e remédio, com um login para cada pessoa da casa. A tela fica aqui
(GitHub Pages) e os dados ficam numa planilha Google do dono, acessada por um Apps Script com senha.
Este repositório não contém dados: só código.

- `index.html`: o app. Na primeira vez, pede o endereço `/exec` da implantação do Apps Script, o usuário e a senha.
- `apps-script/`: código para colar no Apps Script da planilha (veja `apps-script/LEIA-ME.md`).
